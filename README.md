# 识谱小达人 · 华为平板安装说明（PWA）

把网页版「识谱小达人」封装成 **PWA（渐进式 Web 应用）**。装好之后：

- 在平板上生成一个**独立 App 图标**，点开全屏运行，和普通 App 没区别；
- **首次打开后完全离线可用**——没网也能练识谱；
- **不需要应用商店、不需要签名、不用华为开发者账号**；
- 手机、平板、电脑通用，同一份文件。

---

## 一、目录里都是什么

| 文件 | 作用 |
|------|------|
| `index.html` | 应用本体（自包含：乐理 + Bravura 记谱字形 + 界面，无任何外部依赖） |
| `manifest.webmanifest` | PWA 清单：名称、图标、全屏方式、主题色 |
| `sw.js` | Service Worker：首次打开时把整个应用缓存到本地，实现离线 |
| `icons/` | 应用图标（192 / 512 / 适配华为圆角裁切的 maskable 512） |
| `serve.js` | 本机预览用的迷你服务器（仅用于电脑上测试） |

---

## 二、方法一：先在电脑上看效果

需要本机装了 Node.js。在本 `pwa` 目录下执行：

```bash
node serve.js
```

然后浏览器打开 `http://localhost:8080`。
（`localhost` 属于浏览器的"安全上下文"，所以能在本机直接把 PWA **装到电脑上**测试：Chrome 地址栏右侧会出现"安装"图标。）

---

## 三、方法二：装到华为平板

> **关键点**：浏览器只在 **https**（或 `localhost`）下允许"安装"和离线缓存。
> 华为平板从局域网 http 地址打开是**不能安装**的，所以要把 `pwa/` 目录整套放到一个 **https 网址**上。

### 推荐做法：GitHub Pages（免费、自带 https，最省事）

1. 注册 GitHub 账号，新建一个仓库（选 **Public**）。
2. 把 `pwa/` 目录里的**全部文件**（含 `icons/` 子目录）上传到仓库根目录。
3. 进入仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
4. 等 1～2 分钟，得到网址：`https://<你的用户名>.github.io/<仓库名>/`
5. 在华为平板上用浏览器打开这个网址即可（见第四节）。

### 其它等效做法

把 `pwa/` 目录整体上传到任意 **支持 https 的静态托管**都可以：
华为云 OBS 静态网站托管、Gitee Pages、Vercel、Netlify、腾讯云 COS 等。

---

## 四、在华为平板上"安装"

1. 用**华为浏览器**或 **Chrome** 打开上面的 https 网址，等页面加载完（首次会后台缓存，稍等几秒）。
2. 触发安装，二选一：
   - **华为浏览器**：地址栏右侧出现「安装」图标，点击即可；或右上角 **≡ 菜单 → 添加到桌面 / 安装应用**。
   - **Chrome**：右上角 **⋮ 菜单 → 添加到主屏幕 / 安装应用**。
3. 确认后，平板桌面出现「**识谱小达人**」图标，点开即为独立全屏应用。
4. **验证离线**：打开平板「飞行模式」再点图标，仍能正常出题、发声 → 说明离线缓存成功。

> 提示：华为平板（HarmonyOS）自带华为浏览器基于 Chromium 内核，对 PWA 支持良好；
> 若某一入口找不到安装项，换另一个浏览器（Chrome / Edge）再试即可。

---

## 五、常见问题

- **没有出现"安装"提示？**
  确认网址是 `https`（不是 `http`）、用的是华为浏览器或 Chrome，并首次多等几秒让 Service Worker 就绪。
- **改了内容怎么更新？**
  重新构建并部署后，把 `sw.js` 里的 `CACHE` 版本号加一（如 `sight-reading-v1` → `v2`），
  再打开一次即可触发更新（浏览器会自动拉取新版本）。
- **想要真正的 `.apk` 安装包（可自由分发）？**
  改用"Android APK 套壳"方案（Capacitor/Cordova 把 `index.html` 包进 WebView），
  见项目主 `README.md`。

---

## 六、重新生成 PWA

应用本体改动后，在项目根目录执行：

```bash
node build.js      # 先重新构建 识谱小达人.html
node make_pwa.js   # 再生成 pwa/index.html（自动注入 manifest 与 SW 注册）
```
